 # Day 1 - Network Basics Lab

## Tools Used
- Windows PowerShell

## Commands Practiced

### ipconfig
Shows network information such as IP address and gateway.

### ping google.com
Tests internet connectivity.

### tracert google.com
Shows the route data takes to reach a website.

## What I Learned
I learned how to check if a network connection is working and how to perform basic troubleshooting using command-line tools.

## Outcome
I can now use basic networking commands to diagnose connection issues.
