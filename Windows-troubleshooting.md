# Day 2 - Windows Troubleshooting Basics

## Objective

To learn how to gather basic system information using Windows command-line tools.

## Commands Used

### hostname

Command:

hostname

Purpose:
Displays the name of the computer.

Why It Is Important:
Helps identify a specific device when troubleshooting or managing multiple computers.

### whoami

Command:

whoami

Purpose:
Displays the currently logged-in user account.

Why It Is Important:
Helps verify which user is currently using the computer and assists with troubleshooting account and permission issues.

### systeminfo

Command:

systeminfo

Purpose:
Displays detailed information about the operating system and computer hardware.

Information Obtained:

* Operating System Name
* Operating System Version
* System Type
* Memory Information
* Installation Date

Why It Is Important:
Provides useful information required for troubleshooting and system administration tasks.

## Skills Learned

* Device identification
* User identification
* System information gathering
* Basic troubleshooting techniques

## Real-World Application

IT Support technicians and System Administrators often gather information about a computer before diagnosing or resolving problems.

The commands hostname, whoami, and systeminfo provide important details about the system and user.

## Conclusion

This lab demonstrated how to identify a computer, determine the active user, and gather system information using built-in Windows commands.
